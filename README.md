# CODE-OF-CONDUCT
Description

This project is a simple interest calculator. It calculates the simple interest based on the principal amount, interest rate, and time period.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

Principal = Initial amount
Rate = Interest rate per year
Time = Time period in years
Example

If the principal amount is 1000, the interest rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Therefore, the simple interest is 100.
